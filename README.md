# 🌤️ Weather Prediction App

A clean, simple frontend application that fetches and displays real-time weather data. 

## 🎯 Overview
This project was built to practice working with live data. It connects to the OpenWeather API to provide users with accurate and up-to-date weather conditions for any given location. 

## 🚀 Tech Stack
* **HTML:** Structure of the web page.
* **CSS:** Styling and visual layout.
* **JavaScript:** Handling the logic and fetching data from the OpenWeather API.

## ✨ Features
* Real-time weather data retrieval.
* Simple, user-friendly interface.
* Fast and responsive frontend.

## 🛠️ How to Run Locally
Because this is a simple frontend project, you don't need any complex setup!
1. Download or clone this repository.
2. Open the folder on your computer.
3. Double-click the `index.html` file to open it in your default web browser.
